# Life Expectancy Prediction using Machine Learning

## 📌 Project Overview

This project focuses on predicting and analyzing life expectancy using machine learning techniques.

The project uses the **Life Expectancy Data** dataset, which contains health, demographic, social and economic information for different countries.

Two machine learning algorithms are implemented:

1. **Linear Regression**
2. **Logistic Regression**

Linear Regression is used to predict the actual life expectancy value, while Logistic Regression is used to classify life expectancy into two categories:

- Below 65 years
- 65 years or above

The project also includes an interactive **Streamlit web application** where users can explore the dataset, view model performance and enter feature values to obtain predictions.

---

# 🎯 Project Objectives

The main objectives of this project are:

- Understand and analyze the Life Expectancy dataset.
- Perform data preprocessing.
- Handle missing values.
- Separate numerical and categorical features.
- Encode categorical data.
- Scale numerical features.
- Split the dataset into training and testing sets.
- Train a Linear Regression model.
- Train a Logistic Regression model.
- Evaluate both models using appropriate metrics.
- Generate a classification report.
- Generate a confusion matrix.
- Build an interactive prediction interface.
- Deploy the machine learning application.
