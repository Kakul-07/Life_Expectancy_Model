# Life Expectancy Prediction using Machine Learning

## Project Overview

This project predicts life expectancy using machine learning techniques.

The project uses the Life Expectancy dataset and applies Exploratory Data Analysis, feature selection, preprocessing, Linear Regression and Logistic Regression.

A Streamlit web application is also created so users can enter important health and socioeconomic information and get a life expectancy prediction.

## Objectives

- Analyze the Life Expectancy dataset
- Perform Exploratory Data Analysis
- Handle missing values
- Select important features
- Build a Linear Regression model
- Build a Logistic Regression model
- Evaluate both models
- Create an interactive Streamlit application
- Deploy the application using Streamlit Cloud
